# Travel Recommendation Website

A simple single-file travel recommendation website built with HTML and CSS.

## Pages

- **Home** - Hero introduction, search bar, featured destinations, and a stats strip
- **About Us** - Company story, core values, and team members
- **Contact Us** - Contact details and an inquiry form

## How to Run

No server or install needed. Just open the file in any browser:

```
index.html
```

## Files

```
index.html - the entire website (HTML + CSS + JS in one file)
README.md - current file
```

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts - Playfair Display & Jost
- Unsplash - destination photos
